# Rock Paper Scissors Game in Java 🎮

A simple, classic console-based **Rock, Paper, Scissors** game written in Java. Play against the computer and see who can reach **3 wins** first!

---

## Features
* **Interactive Console Gameplay:** Type your moves (`rock`, `paper`, or `scissors`) directly into the terminal.
* **Input Validation:** Automatically handles casing and catches invalid typos.
* **Score Tracking & Immediate Win Check:** Keeps track of the score and stops the game the exact second someone hits 3 points.

---

## Prerequisites
To run this game, you need to have **Java** installed on your computer. 
* Check if Java is installed by running `java -version` in your terminal.

---

## How to Run
1. Clone or download this repository to your local machine.
2. Open your terminal or command prompt in the folder containing `hezer.java`.
3. Compile the Java file:
   ```bash
   javac hezer.java
